# Portfolio — Joks

Lancer : `npm install` puis `npm run dev` (http://localhost:5173). Build : `npm run build`.

## Où modifier quoi
- `src/data/` : TON CONTENU (profile, skills, projects, services, journey). Les pourcentages, dates et coordonnées sont à ajuster.
- `src/sections/` : une section par fichier (Hero, About, Skills, Projects, Services, Journey, Contact)
- `src/components/` : Navbar, Footer, Section, Reveal
- `src/index.css` : couleurs et police (bloc @theme)
- Photo et CV : mets-les dans `public/` puis renseigne `photo` et `cv` dans `src/data/profile.js`
